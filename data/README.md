# Data Directory

This directory should contain your dataset files:

## Required Files

1. **Music Info.csv** - Track metadata with audio features
2. **User Listening History.csv** - User interaction data (optional)

## File Format

See `DATA_FORMAT.md` in the root directory for detailed format specifications.

## Data Sources

- Spotify Web API
- Last.fm datasets
- Million Song Dataset
- Your own music collection data

## Note

Data files are not included in this repository due to size constraints. 
Please obtain your own datasets following the format specifications.
